# Provenance

[Corpus concept](personal-knowledge-corpus.md) · [Document ingestion](../user-guide/document-ingestion.md)

Provenance answers “where did this come from?” Sources retain stable IDs,
checksums, import times, extraction locations, and derivation metadata. Knowledge
records carry source IDs/locations and structured provenance. Memory approval
preserves the originating candidate context.

Provenance is kept with canonical records so index rebuilds and provider changes
do not sever the relationship. It supports citation checks, correction history,
and honest distinction between owner-provided evidence and model inference.
